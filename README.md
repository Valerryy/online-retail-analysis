# Анализ продаж интернет-магазина (Online Retail)

Разведочный анализ (EDA) данных британского интернет-магазина подарков
за период декабрь 2010 — декабрь 2011. Цель — изучить продажи, товары,
географию и удержание клиентов и дать рекомендации для бизнеса.

## Инструменты
- Python (Pandas) — обработка и анализ данных
- SQL (DuckDB) — аналитические запросы
- Matplotlib — визуализация
- Google Colab — среда разработки

## Что сделано
- Загрузка и очистка данных (~540 тыс. строк: удаление пропусков, возвратов, дубликатов)
- Анализ выручки по месяцам, топ-товаров и топ-стран
- SQL-запросы: агрегации, подзапрос, оконные функции, CTE
- Когортный анализ удержания клиентов (retention)

## Ключевые выводы
- Выручка ~£8.9 млн от 4338 клиентов; бизнес держится на оптовых покупателях
- Выраженная сезонность: пик продаж приходится на осенне-зимний период
- 82% выручки даёт Великобритания — высокая зависимость от одного рынка
- В среднем лишь ~21% новых клиентов возвращаются в следующий месяц

## Рекомендации
- Готовиться к сезонному пику заранее (запасы и маркетинг к осени)
- Снижать зависимость от UK: развивать Нидерланды, Ирландию, Германию, Францию
- Повышать удержание через email-рассылки и скидки на повторную покупку
